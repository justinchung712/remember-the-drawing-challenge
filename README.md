# Remember the Drawing Challenge

This JavaFX game is based on the viral "Remember the Drawing Challenge", in which players draw a sequence of simple objects with little to no time, then try to identify the objects in their own drawings.

## Requirements

- JDK 24
- Maven

## Running the Project

Clone the repository:
```
git clone https://github.com/justinchung712/remember-the-drawing-challenge.git
cd remember-the-drawing-challenge
```

Then run:
```
mvn clean javafx:run
```
